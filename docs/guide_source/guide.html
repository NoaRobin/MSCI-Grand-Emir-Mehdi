Le parcours le plus court

Décompresser le dossier, double-cliquer sur lancer.bat, cliquer sur Se connecter à MSCI, coller ses ISIN, cliquer sur Extraire les données, puis sur Télécharger l'Excel. Le reste du guide détaille chacune de ces étapes.

1À quoi sert l'application

Vous avez une liste de codes ISIN (actions, obligations, fonds). L'application va chercher chez MSCI les données ESG correspondantes et vous rend un fichier Excel prêt à importer, au format exact attendu par l'équipe.

Vos ISINUn fichier Excel, ou une liste collée à la main.
→
MSCIL'application interroge l'API MSCI ESG à votre place.
→
Le fichier ExcelFeuilles « Template Import Titres » et « Template Import Fonds ».

Ce qui est garanti

  • Le format ne change pas : mêmes feuilles, mêmes colonnes dans le même ordre, mêmes en-têtes que le modèle de l'équipe (94 colonnes pour les titres, 123 pour les fonds).
  • Rien n'est inventé : une valeur que MSCI ne fournit pas reste vide. Un 0 renvoyé par MSCI reste un 0.
  • Vos lignes restent à leur place : l'ordre et les doublons de votre liste sont conservés, même pour un ISIN invalide.
  • Vos identifiants restent sur votre poste : l'application tourne sur votre ordinateur. Elle n'est accessible qu'à vous (adresse 127.0.0.1).

Comment elle trouve un maximum de valeurs

MSCI propose plusieurs « portes d'entrée » à ses données, avec des droits différents selon votre abonnement. L'application les essaie l'une après l'autre, et ne demande à la suivante que ce qui manque encore :

1 · API V4La source principale, toujours interrogée.
2 · API V3Pour les cellules encore vides. Droits souvent plus larges.
3 · HistoriqueDernière valeur publiée, pour ce qui manque encore.

Ces trois couleurs se retrouvent dans l'application : chaque case du fichier prend la couleur de la source qui l'a remplie.

4Se connecter à MSCI

À l'ouverture, le bouton en haut à droite indique Se connecter à MSCI, avec un point rouge. Cliquez dessus.

  • Une fois connecté, le point devient vert et la fenêtre affiche ce que votre abonnement permet de lire : nombre de produits pour les titres et les fonds, accès à l'API V3.
  • Les identifiants saisis ici sont oubliés quand on ferme l'application. Pour ne plus avoir à les saisir, voir l'encadré ci-dessous.
  • Le lien Essayer avec des données fictives active le mode démonstration : un bandeau orange le rappelle, et le fichier produit commence par DEMO_.
Mémoriser ses identifiants (facultatif)
  1. Dans le dossier du projet, copiez le fichier .env.example et renommez la copie en .env (sans rien avant le point).
  2. Ouvrez .env avec le Bloc-notes et complétez les deux lignes : MSCI_CLIENT_ID=… et MSCI_CLIENT_SECRET=…
  3. Enregistrez et relancez lancer.bat.

Ce fichier contient un secret : ne l'envoyez jamais par e-mail et ne le partagez pas. Chacun utilise ses propres identifiants.

5Faire une extraction

  1. Choisir l'onglet : Titres ou FondsTitres pour les actions et obligations (feuille « Template Import Titres »), Fonds pour les parts de fonds (feuille « Template Import Fonds »). On peut remplir les deux avant de lancer.
  2. Ajouter les ISIN, au choix :
    • Déposer un fichier Excel ou CSV sur la zone en pointillés, ou cliquer dessus pour le choisir. Il suffit d'une colonne intitulée ISIN. Des feuilles nommées « Titres » et « Fonds » sont rangées automatiquement dans le bon onglet.
    • Coller une liste dans le cadre, un ISIN par ligne. Depuis Excel, on peut copier les colonnes ISIN, Client_ID et Security_Status ensemble : elles seront recopiées dans le fichier final.
  3. Vérifier la listeSous le cadre, l'application compte les ISIN et signale ceux qui sont mal saisis, avec la raison (longueur, format, faute de frappe). Les liens Retirer les invalides et Retirer les doublons corrigent la liste en un clic.
  4. Cliquer sur « Extraire les données »Les cases de la feuille s'allument au fur et à mesure que MSCI répond : d'abord en vert (API V4), puis en bleu (V3) et en ambre (historique) pour combler les trous. Les étapes en cours s'affichent en haut à droite. Le bouton devient Annuler l'extraction si vous voulez arrêter.

Les options (facultatives)

Le lien Sources et options, sous la liste, permet de désactiver une source ou le cache. Par défaut, tout est activé ; il n'y a normalement rien à changer.

6Lire le résultat

  • Télécharger l'Excel : le fichier import_msci_AAAAMMJJ_HHMM.xlsx arrive dans votre dossier Téléchargements. Il contient toujours les deux feuilles du modèle.
  • Diagnostic : un fichier technique (JSON) qui détaille chaque appel à MSCI. Utile pour le support MSCI ou pour la personne qui maintient l'outil. Il contient vos ISIN : ne le diffusez pas.
  • Passer la souris sur une case affiche la valeur, sa source et sa date. Sur la barre grise du haut, elle indique pour combien de lignes la colonne est remplie.

Les couleurs des cases

CouleurSignification
VertValeur fournie par l'API V4 (source principale).
BleuValeur fournie par l'API V3, pour une case que la V4 laissait vide.
AmbreDernière valeur publiée, issue de l'historique. Vérifier la date au survol.

Les lignes marquées d'un point rouge

MessageCe qu'il faut faire
ISIN invalide, non envoyéCorriger la faute de frappe dans la liste.
ISIN inconnu de MSCIVérifier le code ; MSCI ne couvre pas tous les titres.
Aucune donnée retournéeMSCI connaît le titre mais n'a rien envoyé.

Joignez une capture de la fenêtre noire et, si possible, le fichier Diagnostic de l'extraction (en interne uniquement : il contient vos ISIN). Le diagnostic contient les identifiants d'appel trace_id que le support MSCI demandera. Il ne contient jamais vos identifiants MSCI.

8Reprendre le projet

Cette partie s'adresse à la personne qui maintient l'outil. Pas besoin d'être développeur pour les tâches courantes (modifier une colonne, mettre à jour les identifiants) ; un peu de Python aide pour le reste.

Modifier d'où vient une colonne

Chaque colonne du modèle a une règle dans app/data/mapping.json, dans le même ordre que dans Excel. Exemple :

"ESG_RATING_DATE": { "kind": "msci", "candidates": ["ESG_RATING_DATE", "IVA_RATING_DATE"], "note": "IVA_RATING_DATE = « ESG Rating Date » dans le catalogue MSCI." }
  • candidates : les codes MSCI essayés dans l'ordre ; le premier qui a une valeur l'emporte. Les codes exacts se trouvent dans le catalogue MSCI ESG & Climate Historical Data API Catalog, colonne Factor Column Header.
  • Autres valeurs possibles de kind : input (recopié depuis la saisie), input_isin (l'ISIN saisi), blocked (laissé vide volontairement).
  • Ouvrir le fichier avec le Bloc-notes, modifier, enregistrer, relancer lancer.bat. Si une virgule ou un guillemet manque, l'application refuse de démarrer et indique pourquoi.
Ajouter ou renommer une colonne du modèle

Il faut modifier les deux fichiers ensemble : la feuille dans app/data/template.xlsx, et la règle correspondante dans mapping.json, au même rang. L'application vérifie au démarrage que les deux correspondent exactement, et refuse de démarrer sinon : on ne peut pas produire un fichier au mauvais format par accident.

Comment se déroule une extraction

  1. Catalogue : l'application demande à MSCI la liste des codes que la V4 connaît pour votre compte, et n'envoie à la V4 que ceux-là.
  2. API V4 : requêtes par paquets de 100 émetteurs (50 fonds) et 100 codes, avec la reprise des valeurs de l'émetteur parent.
  3. Fonds seulement : un ISIN de part que /funds ne reconnaît pas est traduit en identifiant MSCI (MDSUID) grâce au référentiel /coverage.
  4. API V3, puis historique : seulement pour les cases encore vides.
  5. Écriture : une copie de template.xlsx est remplie ligne à ligne ; les en-têtes et styles d'origine sont conservés.

Solidité

  • MSCI saturé (erreur 429) ou en maintenance (503) : nouvelles tentatives automatiques, en respectant le délai demandé par MSCI.
  • Un paquet en erreur n'arrête pas tout : ses lignes sont marquées, le reste est livré. Un paquet refusé (erreur 400) est coupé en deux jusqu'à trouver l'ISIN qui pose problème.
  • Une source refusée (V3 non souscrite, par exemple) est signalée ; les autres sont utilisées.
  • Réponses gardées 6 heures en mémoire : une relance ne refait que les appels manquants.

Sécurité

  • Le fichier .env n'est jamais envoyé sur GitHub : il est exclu par .gitignore. Ne jamais y mettre les identifiants de quelqu'un d'autre.
  • L'application n'est accessible que depuis le poste qui la lance. Elle n'écrit ni le secret ni le jeton MSCI dans les fichiers de diagnostic.
  • Les fichiers produits contiennent des données de portefeuille et des données MSCI sous licence : respecter les règles de diffusion de l'entreprise et du contrat MSCI.

9Glossaire

TermeDéfinition
ISINCode international à 12 caractères qui identifie un titre (ex. GB00BTK05J60). Le dernier chiffre est une clé de contrôle, ce qui permet de repérer les fautes de frappe.
APIPorte d'accès par laquelle un programme interroge MSCI, sans passer par un site web.
API V4, V3Deux versions de l'API MSCI ESG. La V4 suit les nouveaux produits MSCI ; la V3 suit les droits d'ESG Manager. Elles peuvent donner accès à des données différentes.
HistoriquePartie de l'API qui conserve les valeurs passées ; l'application en reprend la plus récente.
Client ID, Client secretIdentifiant et mot de passe de l'application auprès de MSCI, fournis par le MSCI Customer Center.
Jeton (token)Autorisation temporaire (24 h) que MSCI délivre en échange des identifiants. L'application la gère seule.
ÉmetteurLa société ou l'entité qui émet un titre. Les données ESG sont le plus souvent attachées à l'émetteur.
MDSUIDIdentifiant interne MSCI d'un fonds, que l'application retrouve à partir de l'ISIN de la part.
CacheMémoire temporaire des réponses MSCI, pour ne pas redemander la même chose.
.envPetit fichier texte de réglages personnels (identifiants, port). Jamais partagé.
lancer.batLe fichier à double-cliquer pour démarrer l'application sous Windows.
